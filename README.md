# Aurelia — jewellery website

Baseline React app for a jewellery storefront, ready to host on [Vercel](https://vercel.com).

## Local

```bash
npm install
npm run dev
```

Open the URL Vite prints (usually `http://localhost:5173`).

## Deploy to Vercel

1. Push this folder to GitHub, GitLab, or Bitbucket.
2. Import the repo in the Vercel dashboard.
3. Leave the defaults: Vite is detected automatically (`npm run build`, output `dist`).

Or from the terminal after installing the Vercel CLI:

```bash
npx vercel
```
